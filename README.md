# نظام محاسبي متكامل - Integrated Accounting System

## نبذة عن المشروع
نظام محاسبي شامل ومتقدم يدعم العمليات المحاسبية المعقدة مع واجهة سهلة الاستخدام.

## المميزات الرئيسية

### 1. إدارة الحسابات
- حسابات العملاء والموردين
- حسابات المراكز المالية
- إدارة أنواع الحسابات
- الرصيد الافتتاحي والختامي

### 2. العمليات المحاسبية
- إدارة القيود المحاسبية
- الإيصالات والسندات
- العمليات النقدية
- التحويلات المصرفية

### 3. إدارة المخزون
- تتبع الأصناف والمنتجات
- إدارة المستودعات والفروع
- تحديث الكميات والأسعار
- تقارير حركة المخزون

### 4. المبيعات والشراء
- إدارة الطلبات والفواتير
- عمليات الإرجاع
- إدارة الأسعار والخصومات
- التسليم والتوصيل

### 5. الموارد البشرية
- إدارة الموظفين
- حساب الرواتب والمكافآت
- إدارة الإجازات والحضور
- الراتب والاستحقاقات

### 6. التقارير والتحليلات
- ميزان المراجعة
- قائمة الدخل
- الميزانية العمومية
- تقارير التحليل المالي

### 7. دعم اللغات
- اللغة العربية
- اللغة الإنجليزية
- لغات إضافية

## البنية التقنية

### الطبقات المعمارية
```
Accounting-System/
├── API/                    # واجهات برمجية
├── Core/                   # المنطق الأساسي
├── Data/                   # طبقة البيانات
├── Models/                 # نماذج البيانات
├── Services/               # خدمات الأعمال
├── UI/                     # واجهات المستخدم
├── Tests/                  # الاختبارات
└── Documentation/          # التوثيق
```

## التقنيات المستخدمة
- **لغة البرمجة:** C#
- **Framework:** .NET Framework / .NET Core
- **قاعدة البيانات:** SQL Server / MySQL
- **الواجهات:** WinForms / WPF / ASP.NET
- **ORM:** Entity Framework

## متطلبات التثبيت
- Visual Studio 2019 أو أحدث
- .NET Framework 4.8 أو .NET 6+
- SQL Server 2016 أو أحدث
- 2 GB RAM بحد أدنى

## خطوات البدء

1. استنساخ المستودع:
```bash
git clone https://github.com/a2526034828-art/accounting-system.git
```

2. فتح المشروع في Visual Studio

3. استعادة المكتبات:
```bash
dotnet restore
```

4. تشغيل قاعدة البيانات:
```bash
dotnet ef database update
```

5. تشغيل المشروع:
```bash
dotnet run
```
